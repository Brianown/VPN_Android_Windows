轻隧 LiteTunnel v1.1.0 客户端安装说明
=====================================

Android
-------
1. 把 LiteTunnel-Android-v1.1.0.apk 传到手机；
2. 允许“安装未知来源应用”；
3. 安装后打开，点右下角 +，扫码 / 粘贴 / 导入服务端生成的 .conf；
4. 点节点，按系统提示允许 VPN。
5. 可以添加多个不同服务器的配置；列表显示服务器 IP、位置、类型、延迟。
6. 右上角菜单 → 路由模式：
   - 全局代理：全部流量走 VPN；
   - 智能分流：国外 IP 走 VPN，国内 IP 和局域网直连。
   切换后重新连接生效。
7. 连接后状态卡显示服务端统计的“本月流量”，每 60 秒刷新。

Windows
-------
1. 先安装官方 WireGuard for Windows：https://www.wireguard.com/install/
2. 双击 LiteTunnel-Windows-v1.1.0.exe，UAC 选择“是”；
3. 导入或粘贴服务端生成的 .conf（支持一次导入多个）；
4. 选中节点，点击“连接”。
   点击窗口关闭按钮会隐藏到托盘；只有托盘菜单“退出 LiteTunnel”才真正结束进程。
5. 列表显示服务器 IP、位置/类型、TCP 延迟和状态；点击其它节点切换服务器。
6. 工具栏勾选“智能分流（国内直连）”可切换路由模式，重新连接生效。
7. 连接后状态卡显示本月流量，每 60 秒从 VPN 内网 API 刷新。

服务端
------
见 README.md 的“快速开始”，一条命令安装。
安装会同时部署：
- 月度流量统计（VPN 内网 API）；
- TCP 延迟探测（默认 8443，需要在安全组放行）；
- 自动识别机房位置，可用 SERVER_LOCATION/SERVER_TYPE 覆盖；
- 客户端配置自动包含 IP、位置、类型、延迟端口、月度流量地址和 token。

每月最后一天结束（次月 1 日 00:00）清零。

客户端配置在服务器的 /root/litetunnel/clients/ 下，
也可以用 sudo litetunnel add 名称 继续添加。
