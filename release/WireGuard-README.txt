WireGuard for Windows 1.1.1 (amd64)
====================================

本文件是未经修改的官方 WireGuard for Windows MSI 安装包，用于在
download.wireguard.com 无法访问时由 LiteTunnel 客户端自动安装。

- 版本：1.1.1
- 架构：amd64
- 官方来源：https://download.wireguard.com/windows-client/wireguard-amd64-1.1.1.msi
- 项目主页：https://www.wireguard.com/
- 源码：https://git.zx2c4.com/wireguard-windows/
